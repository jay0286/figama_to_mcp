# Figma to Code 변환 비교 연구

Figma 디자인을 코드로 변환하는 다양한 접근 방식을 비교 분석하는 연구 프로젝트입니다.

## 연구 목적

Figma의 AI 기반 코드 변환 플러그인들이 발전하면서, 디자인에서 코드로의 전환이 점점 자동화되고 있습니다. 그러나 자동 생성된 코드가 실제 프로덕션 환경에서 사용 가능한 수준인지, 어떤 후처리가 필요한지에 대한 체계적인 분석은 부족한 상황입니다.

이 프로젝트는 동일한 Figma 디자인(요가 피트니스 앱)을 5가지 방식으로 변환하여 비교합니다:

| 버전 | 변환 방식 | 설명 |
|------|----------|------|
| 원본 | Figma 자체 내보내기 | 레이어 시맨틱 네이밍 후 내보내기 |
| AI-A | AutoName 플러그인 | AI 기반 자동 네이밍 플러그인 적용 |
| AI-B | LayerSense 플러그인 | AI 기반 레이어 분석 플러그인 적용 |
| V1 | 수동 리팩토링 | 컴포넌트 분리 및 구조화 1차 |
| V2 | 심화 리팩토링 | 재사용성과 유지보수성 개선 |

추가로 Flutter로 동일 디자인을 구현하여 크로스 플랫폼 관점의 비교도 제공합니다.

## 프로젝트 구조

```
figma_to_mcp/
├── react-preview/          # React 비교 뷰어 (Vite + Tailwind)
│   ├── src/
│   │   ├── components/
│   │   │   ├── home-v1/    # 리팩토링 V1 컴포넌트
│   │   │   ├── home-v2/    # 리팩토링 V2 컴포넌트
│   │   │   └── shared/     # 공통 컴포넌트
│   │   └── hooks/          # 커스텀 훅
│   └── package.json
│
├── yoga_app/               # Flutter 구현체
│   └── lib/
│       ├── core/           # 테마, 상수
│       ├── features/       # 기능별 모듈 (home, calendar, classes 등)
│       └── shared/         # 공유 모델
│
└── reference/              # Figma 원본 내보내기 (React JSX)
```

### React Preview

5가지 변환 버전을 모바일 프레임(390x844) 안에서 나란히 비교할 수 있는 뷰어입니다. 탭 전환으로 각 버전의 렌더링 결과와 코드 품질을 직접 확인할 수 있습니다.

### Flutter 구현

Feature-first 아키텍처와 Material 3 테마를 적용한 프로덕션 수준의 구현체입니다. 자동 변환 코드를 실제 앱으로 발전시킬 때 필요한 작업량을 가늠하는 기준점 역할을 합니다.

## 연구 인사이트

### 자동 변환의 한계

**1. 네이밍과 구조**
- AI 플러그인은 시각적 요소를 인식하지만, 비즈니스 로직 관점의 네이밍은 부족
- `Frame123`, `Group456` 같은 의미 없는 이름이 `BookedClassCard`, `WeekCalendar`로 변환되어야 함
- 컴포넌트 경계 인식이 불완전하여 재사용 가능한 단위로 분리되지 않음

**2. 스타일 처리**
- 인라인 스타일 과다 생성 → 테마 시스템으로 통합 필요
- 반응형 대응 부재 → 고정 픽셀값 대신 상대 단위 적용 필요
- 다크모드 미고려 → 시맨틱 컬러 토큰으로 재정의 필요

**3. 상태 관리**
- 정적 UI만 생성되어 인터랙션 로직은 전부 수동 구현 필요
- 데이터 바인딩, 이벤트 핸들링 코드 부재

### AI 플러그인 비교

| 항목 | AutoName (A) | LayerSense (B) |
|------|--------------|----------------|
| 네이밍 정확도 | 시각적 특징 기반 | 컨텍스트 인식 시도 |
| 컴포넌트 분리 | 단순 그룹핑 | 의미 단위 분리 시도 |
| 코드 품질 | 즉시 사용 어려움 | 약간의 후처리로 사용 가능 |

### 리팩토링 단계별 개선

- **V1**: 컴포넌트 분리, Props 정의, 기본 타입 적용
- **V2**: 커스텀 훅 추출, 공통 컴포넌트 통합, 테마 시스템 적용

## 실행 방법

### React Preview

```bash
cd react-preview
npm install
npm run dev
```

`http://localhost:5173`에서 5가지 버전을 탭으로 전환하며 비교할 수 있습니다.

### Flutter 앱

```bash
cd yoga_app
flutter pub get
flutter run
```

iOS 시뮬레이터 또는 Android 에뮬레이터에서 실행됩니다.
